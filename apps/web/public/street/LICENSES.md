# Street View assets

Every 3D model in Street View is procedural geometry written in code (apps/web/street/Building.tsx, Equipment.tsx, Nodes.tsx). There are no downloaded models, textures or HDRIs in this release.

| Asset | Source | Licence |
|---|---|---|
| Building, facade, canopy, rooms | Procedural (this repository) | Project licence |
| Chillers, pumps, panels, transformers, UPS, DG, medical gas, STP, laundry, kitchen, beds, MRI/CT, cath lab, OT, solar arrays, heat pumps, tanks, cooling towers, EV chargers | Procedural (this repository) | Project licence |

Any CC0 model added later (Kenney, Quaternius, Poly Haven) is listed here with its URL and licence before it is committed (rule 15).
