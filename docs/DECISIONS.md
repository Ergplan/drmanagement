- 2026-11-27: Simulator calibration fits only what the bills support: per-month MD (evening factor), May–Sep and Nov energy; cooling rates are physical priors; heat-wave response 6%/°C.
- 2026-11-27: Backfill reuses the live driver + collector minute by minute, so history and live data come from one code path.
- 2026-11-27: Edge offline buffer uses Node's built-in node:sqlite (no native dependency).
- 2026-11-27: Interlock limits and the ceiling ladder's commands are structured fields in reference/control.yaml (points, min, max, fresh_s; commands per stage); the edge reads them, the database keeps them in site.facts.control. No thresholds in code.
- 2026-11-27: The ceiling owns any asset it holds: DR and the heat-pump scheduler cannot change or release it. Anything that adds load back (restore, run) waits while projected block kVA ≥ Stage 1; only an interlock or control-fault abort forces restores (clinical safety beats savings).
- 2026-11-27: No projection (meter missing) is treated as being at the ceiling, so nothing is added back; the meter-fresh interlock then blocks new commands.
- 2026-11-27: Edge refusals aimed at protected/critical assets are stored in audit_log, because the command table's trigger refuses those asset ids outright.
- 2026-11-27: The DR planner skips loads whose longest safe hold is shorter than the window (e.g. chiller and AHU, 2 h, for a 2.5 h event) rather than planning a mid-event release; the plan says so.
- 2026-11-27: Intent pull is a signed GET as locked; acks go in a separate signed POST /api/edge/intents/ack.
- 2026-11-27: The duty-engineer-armed interlock is an edge setting (ENGINEER_ARMED) until a paging integration reports reachability.
- 2026-11-27: Report PDFs are kept in the VM database by default (bytea on `report`), so hospital data stays in the jouleWise GCP project as with the database decision; Vercel Blob (locked decision) is used when REPORTS_IN_BLOB=1. Blob URLs are public-but-unguessable, so Blob needs the user's agreement before it is switched on.
- 2026-11-27: Settlement values the event by the avoided demand charge on the month's peak (tariff engine) plus any programme payment minus shortfall penalty. Shifted energy is valued at zero because the HV-1 tariff has no time-of-day rate.
- 2026-11-27: The day-matching adjustment window ends before any pre-conditioning starts, so pre-cooling or pre-charging cannot inflate the baseline.
- 2026-11-27: The edge restores every commandable load when it starts, because it cannot know what an earlier run left curtailed (a real device keeps its last command).
- 2026-11-27: Hospital energy benchmark 10,000–20,000 kWh per bed a year and 200–300 kWh/m² (CAHO 2017, private multi-speciality), stored in reference/site.yaml with its source.
- 2026-11-27: Minute-level cloud jobs (OpenADR poll, escalation) run from a signed edge call every 5 minutes, not Vercel Cron, so the plan tier does not matter and nothing runs when the edge is offline (the edge is the site's heartbeat anyway).
- 2026-11-27: OpenADR and DISCOM signals never become commands directly: each creates a proposed event with ergOS's plan under programme 'discom' (baseline high 5 of 10 like days) that needs the full approval chain. The VEN is behind a feature flag (OPENADR_VTN_URL).
- 2026-11-27: Ask ergOS uses the Anthropic Messages API (model from ASSISTANT_MODEL) with read-only tools only; there is no write tool, so it cannot create intents, approvals or commands (invariant 8).
- 2026-11-27: Point mapping is recorded in the database for review, but the edge still takes it from edge.config.yaml (invariant 10); the page prints the override lines to copy.
- 2026-11-27: Ceiling restores are load-aware: a held load comes back only if projected kVA plus its expected kW (the stage's expect_kw shared across its commands, from control.yaml) stays under Stage 1. The scenario suite found restore/re-shed flapping on a hot evening without it.
- 2026-11-27: Simulated OT and isolation pressures moved away from the trip limits (OT +18 to +19 Pa, isolation −13 Pa, smaller noise); the earlier values caused nuisance trips every few hours that aborted events. Real nuisance trips are a commissioning item, not something to debounce away.
- 2026-11-27: Decisions on DR events need an approver role (facility manager, medical superintendent, duty engineer); other roles get 403 before the workflow runs.
- 2026-11-27: The edge takes a pid lock next to its outbox and refuses to start a second copy; two copies would pull the same intents and double every command (found when stale test processes overlapped).
- 2026-11-27: Demo admin (user's request): with DEMO_ADMIN=1, admin/admin signs in and can act as any role from the top bar; decisions are recorded as admin with the role used. Off by default; must stay off once real meters or real approvers are involved.
